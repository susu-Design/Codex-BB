# Reaction GIFs

Local prototype only. Generated with the built-in image generation tool, then
encoded from eight sprite frames using Pillow. Each cycle is 1800 ms, 256x256,
with transparent GIF backgrounds. The room removes the effect after one cycle;
the preview thumbnails loop for inspection.

Shared generation prompt: Transparent PNG sprite sheet, 4 columns by 2 rows,
eight square cells. Isolated floating 3D facial features only, no head, face disc,
background, border or text. Glossy ivory eyeballs, colored soft-plastic eyelids,
dark eyebrows and small mouth. Fixed center and scale, subtle eye and mouth
motion, generous transparent margins, soft studio lighting.

- hehe: lime green, half-lidded sarcastic smirk; look sideways, raise one brow,
  lower lids, hold, blink, return.
- question: coral orange, skeptical pursed mouth; raise one brow, widen one eye,
  squint the other, glance sideways, open mouth slightly, hold and return.
- applause: lavender, bored half-lidded eyes and crooked smile; two small hands
  approach and touch for two restrained slow claps, slight brow and smile shifts.

GIF uses binary transparency, so edges are less soft than an alpha-video format.
No camera pixels, microphone input or user data are included in these assets.
