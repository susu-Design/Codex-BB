# 来打我啊 · 交互 Demo

情侣远程争执助手的推测性设计展示版。采用纯 HTML、CSS 和 JavaScript，可通过 GitHub Pages 发布。

## 修改与发布

- `index.html`：网页标题、导航与页面入口。
- `app.js`：页面文案、插画、卡牌交互与模拟战报。
- `style.css`：颜色、字体、布局与动画。
- `server.cjs`：可选的本地预览服务，不参与线上运行。

GitHub Pages 使用 `main` 分支的根目录。修改上述文件并提交到 `main` 后，GitHub 会重新发布页面；可在仓库 Actions 页面查看发布状态。浏览器可能需要刷新才能看到最新内容。

可以在 GitHub 网页中打开文件，点击编辑按钮并提交修改；也可以用 GitHub Desktop 将本地修改提交并推送。PRD 研究文档保留在本地，不纳入展示仓库。

## 本地运行与演示范围

打开 index.html 即可体验，或运行 `node server.cjs` 并访问 http://localhost:4173。

包含首页、备战室、模拟视频现场、五张互动卡牌、暂停与恢复、固定 AI 示例战报、原话查看、反馈和删除。

这是单机设计原型，不提供真实双人通信、录音、转写或 AI 推理。摄像头只在主动同意后用于本地预览，不申请麦克风权限；离开现场释放摄像头。数据只存在页面内存中，刷新清空。语音波形是明确标注的模拟动画。

无第三方依赖、外部字体或数据上传。PRD-v0.2.md 包含完整产品目标，未接入的联网、AI 和服务端数据管理不属于本 Demo 已实现能力。
