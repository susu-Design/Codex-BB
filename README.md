# 来打我啊 · 交互 Demo

情侣远程争执助手的产品展示版。采用纯 HTML、CSS 和 JavaScript，可通过 GitHub Pages 发布。

## 修改与发布

- `index.html`：网页标题、导航与页面入口。
- `game.js`：页面文案、双人 WebRTC 通话、房间邀请、互动同步、声音检测与模拟战报。
- `peerjs.min.js`：固定版本的 WebRTC 连接库，随网站一起发布，避免依赖 CDN 加载。
- `THIRD_PARTY_NOTICES.md`：第三方开源软件许可说明。
- `style.css` 和 `game.css`：基础视觉、游戏界面与特效动画。
- `server.cjs`：可选的本地预览服务，不参与线上运行。
- `AI-CONFLICT-DETECTION-PROMPT.md`：隐形对抗识别的系统提示词、输入模板、JSON 输出结构和测试示例。

GitHub Pages 使用 `main` 分支的根目录。修改上述文件并提交到 `main` 后，GitHub 会重新发布页面；可在仓库 Actions 页面查看发布状态。浏览器可能需要刷新才能看到最新内容。

可以在 GitHub 网页中打开文件，点击编辑按钮并提交修改；也可以用 GitHub Desktop 将本地修改提交并推送。PRD 研究文档保留在本地，不纳入展示仓库。

## 本地运行与演示范围

打开 index.html 即可体验，或运行 `node server.cjs` 并访问 http://localhost:4173。

包含首页、秘密诉求、真实双人音视频、邀请链接、卡牌与特效同步、单人示范局、舞台热度、七张鼠标互动卡牌、声音检测自动特效、暂停与恢复、动态战报、对抗性前提提取、互动概览、趣味成就、原话查看、反馈和删除。

真实通话使用 PeerJS 1.5.5 和 WebRTC。发起者点击“创建房间”，复制邀请链接给伴侣；伴侣打开链接并点击加入后，双方分别授权摄像头与麦克风。媒体和互动数据通过 WebRTC 在浏览器之间传输，免费的 PeerJS Cloud 只负责帮助双方建立连接。声音特效只在本地计算音量，不录音；离开现场后会立即释放设备。会议记录只存在页面内存中，刷新清空。

真实通话需要 HTTPS 或 localhost，以及能够访问 PeerJS Cloud 的网络。当前公共信令适合展示和小规模测试；部分严格企业网络或复杂 NAT 环境可能无法连通，正式产品应部署自有 PeerServer 和 TURN 服务。转写、AI 推理、录音和服务端数据管理仍未接入，会后声音曲线和 AI 内容明确标注为模拟内容。
